# Урок 1 — Как устроен современный ИИ

Интерактивный лонгрид урока 1 курса ДПО-1 «Основы применения искусственного интеллекта»: информация о курсе и команде, история ИИ от Тьюринга до ChatGPT, трансформер, LLM как генератор вероятностей, токены и промпт, контекстное окно, выбор нейросети под задачу и слепое сравнение моделей.

**Открыть онлайн:** https://smool-g.github.io/ii-urok-1/

## Что внутри

- `web/kak_ustroen_ii.html` — страница урока: 9 блоков, чек-лист, квиз, выводы.
- `web/*.html` — 8 интерактивных демо (лента истории, механизм внимания, следующее слово, токенизатор, конструктор промпта, контекстное окно, выбор нейросети, LLM Arena).
- `oglavlenie.html` — оглавление курса; `index.html` открывает урок.
- `png/kak_ustroen_ii/` — слайды урока.
- `Docs/` — план страницы и исходный текст урока.
- `tests/` — структурные проверки.

## Локальный запуск

Сборка не нужна — это статический сайт без внешних зависимостей.

```bash
python -m http.server 8000
# открыть http://localhost:8000/
python -m unittest discover -s tests -p "check_*.py" -v
```

Открывайте через HTTP, а не `file://`: страница встраивает демо через iframe.
